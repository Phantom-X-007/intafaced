1. **TV reviewer in 30 seconds** believes this is a real trading / financial OS company — not a payments site, not a Notion page, not a thin startup stub.
2. **Denon feels respected** — his architecture (planes, rooms, laws, chain path, custody law, trade heart, drop energy) is _visible_, not buried and not erased.

4. **Street + AAA game energy** (his words): black glass, bright green, poster type, lobby not bank.
5. **Feels expensive** without Awwwards time sink — craft via **leverage + taste tools**, not freehand CSS soup.
6. **Memorable 3 screenshots**: hero, dual-plane, trade terminal (+ rooms bento).

### Process

7. **No more v2↔v3 thrash** — one content architecture with hard budgets per section.
8. **AFK-capable but not craft-starved** — thrift ≠ delete substance; thrift = reuse components, don’t invent frameworks.

### Explicit non-needles (ignore)

- Pixel-perfect every sub-bullet of Denon pack
- Full quant/execution whitepaper on the marketing surface
- Trading Platform / Broker API pre-grant
- Rebuilding payments apex

## 3 · Content architecture that honors Denon without walls

### Principle

**Section = one job + one visual + short Denon-true copy + optional “read more” disclosure.**  
If a section needs a paragraph longer than ~60 words on first paint, it failed.

### Must-ship narrative spine (all present, none as essays)

| #   | Section        | Denon source                        | First-paint copy budget                              | Visual / component job                                         |
| --- | -------------- | ----------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------- |
| 1   | **Hero**       | HERO + alts (one alt as micro-line) | 3 display lines + ≤35-word sub + 2 CTAs + stat strip | Full-viewport poster; motion glow/grid; optional terminal peek |
| 2   | **Manifesto**  | I short                             | ≤70 words                                            | Split editorial — type is the design                           |
| 3   | **Laws**       | THREE LAWS                          | 3× (title + ≤18 words)                               | 3 asymmetric panels, not identical SaaS cards                  |
| 4   | **Planes**     | II                                  | 2× (title + 4 bullets max) + custody banner          | Interactive plane switcher + strong visual difference          |
| 5   | **Rooms**      | V all 12                            | code + name + **one-line role** (not name-only)      | Dense bento / cockpit grid with hover depth                    |
| 6   | **Systems**    | VI                                  | 3 tabs, ≤40 words each                               | Tabbed identity / balance / token                              |

### Second layer (in disclosure / accordion / modal — still Denon words)

Execution empire, bank, rails, P2P, launch, predict, agents, academy, token flywheel, core — **one accordion group “Inside the house”** with short cards (title + 1–2 lines each).  
**Exists so Denon isn’t “missing.”** Does not dominate scroll.

### Forbidden again

- Auto-pasting full `content.json` bodies into `<p>` chains
- “Good enough” system-ui only with no type system
- Name-only room tiles with zero meaning
- Metrics row as the whole identity (impeccable hero-metric ban still applies — metrics support hero, don’t replace story)
