INTAFACED BRAND KIT
===================

Every file has a transparent background — drop it straight onto any
photo, story, or design.

WHAT'S IN HERE
--------------
01 Logo
   The three-squares symbol on its own.
   Lime = the brand color. Black/White = when lime doesn't fit.
   PNG = ready to use. SVG (vector) = for designers/print, scales to
   any size without losing quality.

02 Wordmark (text only)
   "INTAFACED" in the official brand font (Geist Mono).

03 Logo + Wordmark
   Symbol and name together — the full brand signature.
   File names tell you where to use them:
   "use on dark"  = over dark photos/backgrounds
   "use on light" = over light photos/backgrounds

QUICK RULES
-----------
- Instagram story: just drag any PNG in — they're high-res.
- Don't stretch, recolor, or add effects. Pick the right color
  version instead.
- Brand colors: Lime #C4F000 · Ink (black) #0A0A0A
