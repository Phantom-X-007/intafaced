Under it — the ledger is law:

Double-entry, always. Every transaction sums to zero per asset, in one serializable database transaction. Σ debits = Σ credits, or it doesn't post.
No module holds a balance. Not for fees, not for rewards, not for gas. One wallet graph for the entire OS.
18 decimals of precision. Money is never a floating-point number.
Hash-chained. Every transaction hashes the one before it. A tamper-evident book.
Reconciled hourly. Snapshots must match a full entry replay to 18 decimals. A mismatch pages an operator and freezes the module that diverged.
Recipes only. Deposits, fills, escrow, stake, collateral, liquidation, fees, rewards — approved recipes, never invented balances. No raw database writes from any service. Ever.
